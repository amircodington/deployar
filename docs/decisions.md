# Decisions

Numbered. Do not reverse one without asking Mohammad.

1. **2026-10-22 — Stack = Option A.** `web/` Next.js 16 + TS + Tailwind v4 (pnpm); `agent/` Python 3.13 FastAPI (uv) for the agent loop, Liara client, tools, approval gate, SSE; PostgreSQL 16; Redis 7; Docker Compose; Makefile `dev / check / push-test`. No Django (no data-entry workload).
2. **2026-10-22 — LLM = Mohammad's Claude subscription first.** The agent runs on the Claude Agent SDK (Python), which drives the locally logged-in Claude Code. BoxAPI credit is under $3, so it is not used at the start. The `LLMClient` seam stays so BoxAPI (`https://ai.boxapi.ir/ai/v1`, OpenAI-compatible) can replace it later by env var. Consequence: the agent process runs on Mohammad's Mac (or a machine logged in to his Claude account), not on Liara.
3. **2026-10-22 — Coding-agent fix = Claude Code** through the same Agent SDK (a sub-agent with Read/Edit/Bash in a clone of the user's repo, opens a branch/PR). No separate patch tool, no paid API.
4. **2026-10-22 — Team.** Mohammad builds the software; two university students do R&D, testing, docs and checks. The task book is written for them.
5. **2026-10-22 — Demo = deploy the Torob app (راهبر خرید) (renamed «ترب‌گرد», decision 11) to Liara with this assistant**, then break it on purpose and let the SRE loop find, fix and verify. One scenario feeds both challenge videos.
6. **2026-10-22 — Working name «همکار فنی».** Superseded by #10.
7. **2026-10-22 — Liara account ready** with an API token and ~2,000,000 toman balance for the demo.
8. **2026-10-22 — No amox-os.** Conventions come from `diarman`, `future-mission-2d` and `In-Store-Agent (Torob)`.
9. **2026-10-22 — Test projects = `torob-gard` and `trading-engine (Wallex)`.** Both live in `~/Workspace`; Deployar is tested by deploying and operating them on Liara. Extends #5 (demo app). The trading engine gets its own name later from Mohammad; do not build or deploy it until then. Neither has a git remote yet, and `analyze_repo` reads from GitHub, so each needs a GitHub repo first.
10. **2026-10-22 — Product name = «دیپلویار» (Deployar).** Replaces «همکار فنی» (#6) everywhere: UI, docs, brand, and code identifiers (Python package `deployar`, MCP server `deployar`, env prefix `DEPLOYAR_`). The B-00 evidence and spike keep the old name as history.
11. **2026-10-22 — Demo app name = «ترب‌گرد» (`torob-gard`).** Replaces «راهبر خرید» in #5. It is a Django API with Postgres (PostGIS, pgvector), not Next.js + Prisma; demo details that assumed Next.js get fixed in B-21.
12. **2026-10-22 — The build is watched inside the run, not by a worker job.** `watch_deployment` is a read tool the deploy run calls after `deploy_release`; it polls the release (up to 5 min per call, called again while still building), streams a `deploy_progress` card, probes the URL and emits `live_url`. Reason: the run's SSE stream, checklist and step state already live in the agent process, and a run that ends while the worker reports would need a second stream. The arq worker stays for scheduled jobs (B-18, B-23). Changes BUILD.md B-12's `worker/jobs/watch_deployment.py`.
13. **2026-10-22 — The trading project's name = «تیز» (Tiz).** Completes #9: `trading-engine (Wallex)`, repo `amircodington/wallex-tiz-bot`, Python package `tiz`. It is a single asyncio process (no web port, no DB server; SQLite journal) for the Wallex challenge, ending 2026-10-23 23:50 Tehran. Both ترب‌گرد and تیز are deployed from the same team Liara account; Mohammad's two teammate accounts (about 2,000,000 toman each) stay as reserve.

# LimitationNote

A grey note that says plainly when Liara's API (or GitHub, or DNS) cannot do something, and what the user must do instead.

- First sentence bold in `ink`: what can't be done. Then the one step for the user, and what the assistant will do after.
- Logged as a `limitation_event` every time it is shown; the catalogue of messages lives in the task book (T-limitations).
- Never styled as an error. It is honesty, not failure.
